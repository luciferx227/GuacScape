# GuacScape

**Spr3ad Th3 Lov3**

A dodge-and-collect arcade game made with Unity, playable in the browser.

Steer your cap with the mouse or by dragging on a touch screen. Grab the gold pickups and dodge the sweeping walls, the chasers and the rainbow missiles. One hit and the run is over. Pick your character, enter your IGN, and beat your best score.

Every run is checked by the server and goes on the online leaderboard: the top 10 overall, the top 10 for each character, and the top 100 in a scrollable list, with your own rank shown underneath.

This repository holds the WebGL build served by GitHub Pages.
